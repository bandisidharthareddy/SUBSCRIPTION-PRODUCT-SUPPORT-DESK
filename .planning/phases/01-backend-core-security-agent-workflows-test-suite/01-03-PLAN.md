<task type="auto">
  <name>Task 2: Build Purposeful Support Agent, Diagnostic Tool Runner & Routes</name>
  <files>server/services/toolRunner.js, server/services/agentService.js, server/controllers/agentController.js, server/routes/agentRoutes.js</files>
  <action>
    Create `server/services/toolRunner.js`:
    - `runCheck(ticket, orgId, toolName, fn, timeoutMs = 4000)`: executes tool with `Promise.race` timeout. Logs `ToolRun` document with status ('success' | 'incomplete'), durationMs, and summary. Incomplete checks return error message explicitly without throwing.
    - Tools implemented:
      - `readEntitlements(orgId)`: queries Organization plan and Entitlement records for the authorized org.
      - `readServiceStatus(feature)`: queries active incidents matching the feature keyword.
      - `searchHelp(question, version)`: retrieves relevant guidance.
    Create `server/services/agentService.js`:
    - `answerSupport(question, orgId, ticket, version)`: runs all 3 checks; aggregates grounded evidence string; builds citations list; checks if Ollama model is available. If available, invokes `ChatOllama` with strict prompt; otherwise returns deterministic evidence string. Sets `needsHumanReview: true` if any check was incomplete or no articles found.
    Create `server/controllers/agentController.js` and `server/routes/agentRoutes.js`:
    - `POST /api/support-chat`: customer quick question scoped to `req.session.orgId`.
    - `POST /api/support-agent`: ticket investigation attaching checks and assistant response to ticket conversation.
    - `GET /api/tool-runs`: staff audit log of tool runs for a ticket.
  </action>
  <verify>
    <automated>node -e "Promise.all([import('./server/services/toolRunner.js'), import('./server/services/agentService.js'), import('./server/controllers/agentController.js'), import('./server/routes/agentRoutes.js')]).then(() => console.log('Agent modules loaded successfully'))"</automated>
  </verify>
  <done>Support agent runs diagnostic tools with timeout protections, audit logging, and grounded anti-hallucination answers.</done>
</task>
