  <name>Task 1: Build Security Middleware (Auth, CSRF, Rate Limiting, Role Guards)</name>
  <files>server/middleware/auth.js, server/middleware/csrf.js, server/middleware/rateLimit.js</files>
  <action>
    Create `server/middleware/auth.js` exporting:
    - `requireAuth`: validates `req.session.userId`, returns 401 if missing.
    - `requireRole(...roles)`: checks `req.session.role`, returns 403 if unauthorized.
    - `requireOrg`: checks `req.session.orgId`, returns 403 if missing.
    Create `server/middleware/csrf.js` exporting:
    - `csrfFor(sid)`: generates sha256 HMAC of sessionID using `process.env.CSRF_SECRET`.
    - `csrfMiddleware`: validates `x-csrf-token` header on mutating methods (`POST`, `PUT`, `PATCH`, `DELETE`) for authenticated sessions; bypasses safe methods.
    Create `server/middleware/rateLimit.js` exporting `loginLimiter` (15-min window, max 10 requests).
  </action>
  <verify>
    <automated>node -e "Promise.all([import('./server/middleware/auth.js'), import('./server/middleware/csrf.js'), import('./server/middleware/rateLimit.js')]).then(() => console.log('Security middleware loaded successfully'))"</automated>
  </verify>
  <done>Middleware correctly handles authentication state, role verification, CSRF token validation, and rate limits.</done>
</task>

<task type="auto">
  <name>Task 2: Build Auth Controller, Router, and Express App Factory</name>
  <files>server/controllers/authController.js, server/routes/authRoutes.js, server/app.js</files>
  <action>
    Create `server/controllers/authController.js` implementing:
    - `signup`: Zod validation for name, email, password, organization. Creates User and Org; generates 6-digit verification code hash; links initial Membership with role 'admin' for creator. Logs dev code.
    - `verifyEmail`: validates 6-digit code, marks `emailVerified: true`.
    - `login`: checks password with bcrypt; verifies `emailVerified`; regenerates session storing userId, name, email, role, orgId.
    - `logout`: destroys session, clears cookie.
    - `recovery`: issues password recovery code.
    - `resetPassword`: resets password with verification code.
    - `getMe`: returns current user profile and fresh CSRF token.
    Create `server/routes/authRoutes.js` attaching controller methods to paths.
    Create `server/app.js` exporting configured Express app with helmet, cors, json parser, MongoStore session, csrf middleware, and route mounting.
  </action>
  <verify>
    <automated>node -e "Promise.all([import('./server/controllers/authController.js'), import('./server/routes/authRoutes.js'), import('./server/app.js')]).then(() => console.log('Auth controller and app factory loaded successfully'))"</automated>
  </verify>
  <done>Authentication endpoints and Express app are structured and functional.</done>
